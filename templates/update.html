Update from GitHub

Run this command over SSH on the panel server. It fetches the public main branch, creates code and SQLite backups, installs dependencies in a separate environment, then verifies the running panel.

wget -qO /tmp/beeny-update.sh https://raw.githubusercontent.com/Beni-SHL/beeny-panel/main/scripts/update_panel.sh && sudo bash /tmp/beeny-update.sh --github
  1. Publish this release to GitHub first.
  2. Run the command on the existing panel server.
  3. The updater preserves accounts, config.json, panel.env, certificates, customer uploads and notification secrets.
  4. A failed health check restores the previous application and Python environment. Database changes are additive and never removed during rollback.

After updating older panels

Open an account profile and set Customer login username and password. Existing customer links are locked until credentials are configured. Then configure Customer & payments for your bank card, support contacts, SMTP and Telegram bot.

systemctl status beeny-panel beeny-customer-worker --no-pager
journalctl -u beeny-customer-worker -n 50 --no-pager
