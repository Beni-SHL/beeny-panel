OpenVPN Connect
اندروید
  1. OpenVPN Connect را از Google Play نصب کنید.
  2. کانفیگ را از بخش «کانفیگ‌های شما» بگیرید.
  3. داخل برنامه Import Profile → File را بزنید، فایل را انتخاب و Add کنید.
  4. کلید اتصال را روشن کنید و مجوز VPN را تأیید کنید.
آیفون و آیپد
  1. OpenVPN Connect را از App Store نصب کنید.
  2. فایل کانفیگ را در Files ذخیره کنید.
  3. در برنامه Import Profile → File را بزنید و فایل را وارد کنید.
  4. مجوز ساخت VPN را تأیید کنید و اتصال را روشن کنید.
ویندوز و مک
  1. نسخه رسمی OpenVPN Connect را نصب کنید.
  2. فایل کانفیگ را دانلود کنید و در برنامه Import Profile → File را انتخاب کنید.
  3. فایل را وارد و پروفایل را فعال کنید.
لینوکس
