# Beeny avatar collection

20 original raster avatars generated with image generation, one character per request. Optimized WebP assets are 320 × 320 and do not require an external image service at runtime.

The brief: an original friendly plush fantasy creature, adorable fuzzy fur, high-quality 3D illustration, pale pastel solid background, centered square composition, no text, one unique character only.
